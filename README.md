Веб-приложение «Видеотека» на ASP.NET Core с поддержкой:
- Фильмов (с постерами)
- Жанров
- Клиентов
- Аренды (выдача/возврат)
- Топ популярных фильмов
- Просроченных аренд

## Технологии

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- Docker
- GitHub Actions

```bash
cd VideoLibraryApi
dotnet run
